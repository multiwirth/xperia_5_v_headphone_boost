# Sony Xperia 5 V headphone gain boost for magisk


**Only for Sony Xperia 5 V running LineageOS 24.0**

Changes values in `/vendor/etc/audio/sku_kalama/mixer_paths_kalama_qrd.xml` for RX_Digital_Volume in order to set the "master" volume for headphones out (3.5mm jack) to "84" which translates to 0dB.
This ensures max. output volume for headphones without clipping.



## Requirements
- Sony Xperia 5 V (pdx237) running LineageOS 24.0 rooted via Magisk.
